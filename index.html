1. บทนำและภาพรวมระบบ

Logistics System Demo เป็นระบบบริหารจัดการขนส่งและเอกสารแบบครบวงจร ออกแบบมาเพื่อเพิ่มประสิทธิภาพในการทำงาน ลดขั้นตอนที่ซ้ำซ้อน และติดตามสถานะแบบเรียลไทม์

✨ ฟีเจอร์หลัก

  • Quick Actions - สร้างงานได้ใน 2 คลิก
  • Auto-Complete - ระบบช่วยเติมข้อมูลอัตโนมัติ
  • Timeline Tracking - ติดตามทุกขั้นตอนแบบเรียลไทม์
  • Document Management - ระบบเอกสารพร้อมการขออนุมัติ
  • Role-Based Access - แบ่งสิทธิ์การใช้งานตามตำแหน่ง

2. การเข้าสู่ระบบและสิทธิ์การใช้งาน

2.1 วิธีเข้าสู่ระบบ

  1. กรอกชื่อผู้ใช้และรหัสผ่าน
  2. กดปุ่ม "เข้าสู่ระบบ"
  3. หรือใช้ Quick Login สำหรับการทดสอบ

2.2 ระดับสิทธิ์การใช้งาน

👑 Admin (ผู้ดูแลระบบ)
  • เข้าถึงได้ทุกฟีเจอร์
  • จัดการผู้ใช้งาน
  • อนุมัติการแก้ไขเอกสาร
  • ดูรายงานและสถิติทั้งหมด
📞 CS Team (ฝ่ายบริการลูกค้า)
  • สร้างและจัดการงาน
  • จัดรถและคนขับ
  • สร้างเอกสาร
  • ติดตามสถานะ
🚚 Driver (คนขับรถ)
  • ดูงานของตัวเอง
  • อัพเดทสถานะการขนส่ง
  • ดูรายละเอียดเส้นทาง
📄 Documentation (ฝ่ายเอกสาร)
  • สร้างและจัดการเอกสารทั้งหมด
  • ยื่นขออนุมัติหน่วยงานรัฐ
  • ติดตามสถานะเอกสาร
  • สร้าง Invoice

3. Dashboard และ Quick Actions

3.1 หน้า Dashboard

Dashboard แสดงภาพรวมการทำงานทั้งหมด ประกอบด้วย:

  • Quick Actions - ปุ่มทำงานด่วน 4 ปุ่มหลัก
  • สถิติแบบเรียลไทม์ - จำนวนงาน, กำลังขนส่ง, รอข้าม, บรรทุก
  • รายการงานล่าสุด - แสดงงาน 20 รายการล่าสุด
  • ช่องค้นหา - ค้นหาด้วย RN, เบอร์ตู้, ลูกค้า

3.2 Quick Actions - ทำงานได้เร็วขึ้น 3 เท่า

🚀
สร้างงานใหม่

เปิดฟอร์มสร้างงานพร้อม Auto-generate RN Number

🚚
จัดรถ

เลือกงานและจัดรถพร้อมคนขับทันที

📍
อัพเดทสถานะ

อัพเดทสถานะงาน เช่น ถึงล้ง, ออกจากล้ง, ถึงด่าน

📄
สร้างเอกสาร

สร้างเอกสารส่งออกและขอใบอนุญาต

4. การจัดการงานขนส่ง

4.1 สร้างงานใหม่ (Step by Step)

  1. คลิก Quick Action "🚀 สร้างงานใหม่"

    ระบบจะ Auto-generate RN Number ให้อัตโนมัติ (เช่น RN20260510-001)

  2. กรอกข้อมูลพื้นฐาน
    • CB Number - เลขที่คำขอส่งออก
    • วิธีข้าม - เลือกประเภทงาน
    • เบอร์ตู้ - พิมพ์ 3 ตัวแรกจะมี Auto-suggest
    • ขนาดตู้ - 40HC, 40HR, 45HR
  3. กรอกข้อมูลลูกค้าและสถานที่

    ใช้ Auto-complete โดยพิมพ์ชื่อ ระบบจะแนะนำพร้อมข้อมูลติดต่อ

  4. เลือกสินค้าและปลายทาง

    เลือกจาก Dropdown หรือพิมพ์ค้นหา

  5. คลิก "✅ สร้างงาน"

    งานจะถูกสร้างและแสดงในรายการทันที

4.2 ดูรายละเอียดงาน

คลิกที่รายการงานใด ๆ จะเปิดหน้าต่างรายละเอียดที่แสดง:

  • ข้อมูลงานทั้งหมด - ตู้, ลูกค้า, สินค้า, ปลายทาง
  • Timeline - แสดงประวัติทุกขั้นตอนพร้อมเวลา
  • สถานะปัจจุบัน - กำลังทำอะไรอยู่
  • เอกสารที่เกี่ยวข้อง - ลิงก์ไปยังเอกสารทั้งหมด

4.3 สถานะของงาน

รอดำเนินการ - งานถูกสร้างแล้ว รอจัดรถ
กำลังบรรทุก - รถเข้าล้งแล้ว กำลังขึ้นสินค้า
กำลังขนส่ง - รถออกจากล้งแล้ว กำลังเดินทาง
รอข้ามด่าน - ถึงด่านแล้ว รอผ่านด่าน
ส่งมอบแล้ว - ส่งมอบสินค้าเรียบร้อย

5. ระบบเอกสารและการขออนุมัติ

⚠️ สำคัญมาก!

ระบบเอกสารมี Workflow การอนุมัติ 3 ระดับ เพื่อให้แน่ใจว่าข้อมูลถูกต้องก่อนยิงใบขน

5.1 ประเภทเอกสาร

📋 ใบรับรอง (Certificate)

- ใบรับรองถิ่นกำเนิดสินค้า (พ.ก.7)
- ใบรับรองสุขอนามัย
- ใบรับรอง GAP

💰 Invoice & Packing List

- Invoice ต้นฉบับ
- Packing List
- Sales Contract

📦 ใบขน (Customs Declaration)

- ใบขนส่งออก (Export Declaration)
- เอกสารประกอบการผ่านด่าน

5.2 สถานะเอกสาร (Document Status Flow)

1️⃣ สร้างเอกสาร
เจ้าหน้าที่สร้างเอกสารและกรอกข้อมูล
2️⃣ รอตรวจสอบภายใน
หัวหน้าทีมตรวจสอบความถูกต้อง (1-2 ชั่วโมง)
3️⃣ ยื่นขออนุมัติหน่วยงานรัฐ
ส่งเอกสารไป กรมการค้าต่างประเทศ/สำนักงานมาตรฐาน (1-3 วัน)
4️⃣ ได้รับการอนุมัติ
ได้รับเลขที่อนุมัติและตราประทับ
5️⃣ พร้อมยิงใบขน ✅
สามารถส่งข้อมูลเข้าระบบศุลกากรได้

5.3 การติดตามเอกสารของตู้

ในหน้า "รายละเอียดงาน" จะมีส่วน "📄 เอกสารประกอบ" แสดง:

เลขที่: P-SSC25N008
อนุมัติแล้ว
Invoice
เลขที่: INV-2026-0423
อนุมัติแล้ว
ใบขนสินค้าขาออก
รออนุมัติจากศุลกากร
รอศุลกากร
✅ สรุป: ครบ 2/3 เอกสาร - รอเอกสารใบขนอนุมัติ

5.4 การขอแก้ไขเอกสาร (Approval Workflow)

หากต้องแก้ไขเอกสารที่ผ่านการอนุมัติแล้ว ต้องผ่านการอนุมัติจากหัวหน้างาน:

  1. เจ้าหน้าที่กด "✏️ ขอแก้ไข" และระบุเหตุผล
  2. ระบบส่งการแจ้งเตือนไปหัวหน้างาน
  3. หัวหน้าตรวจสอบและอนุมัติ/ปฏิเสธ
  4. ถ้าอนุมัติ → แก้ไขได้ + บันทึก Log
  5. ถ้าปฏิเสธ → เอกสารยังคงเดิม

5.5 รายงานสถิติเอกสาร

ระบบบันทึก Log ทุกการเปลี่ยนแปลงและแสดงสถิติ:

  • จำนวนเอกสารที่สร้างแต่ละประเภท
  • เวลาเฉลี่ยในการอนุมัติ
  • อัตราการแก้ไข/ยกเลิก
  • ผู้ทำงานแต่ละคน - ประสิทธิภาพ

6. Workflow การทำงานแบบเต็ม

📋 ขั้นตอนการทำงานตั้งแต่ต้นจนจบ

1. รับออเดอร์จากลูกค้า

✓ ลูกค้าแจ้งความต้องการ
✓ CS Team สร้างงานในระบบ (RN Number)
✓ บันทึกข้อมูลสินค้า ปลายทาง ล้ง

2. จัดรถและคนขับ

✓ ตรวจสอบรถว่าง
✓ มอบหมายคนขับ
✓ ส่งรายละเอียดให้คนขับผ่านระบบ

3. เข้ารับสินค้าที่ล้ง

✓ คนขับเข้าล้งตามเวลานัด
✓ อัพเดทสถานะ "เข้าล้ง"
✓ บรรทุกสินค้า ปิด SEAL
✓ อัพเดท "ออกจากล้ง" พร้อมเวลา

4. เตรียมเอกสาร (พร้อมกับขั้นตอน 3)

✓ ทีมเอกสารสร้าง Invoice + Packing List
✓ ยื่นขอใบรับรอง (พ.ก.7)
✓ รอการอนุมัติจากกรมการค้า (1-3 วัน)
✓ ได้รับเอกสารครบ → เตรียมยิงใบขน

5. ขนส่งและผ่านด่าน

✓ อัพเดท "กำลังขนส่ง"
✓ ถึงด่าน → "รอข้ามด่าน"
✓ ยิงใบขนเข้าระบบศุลกากร
✓ ผ่านด่าน → "ข้ามด่านแล้ว"

6. ส่งมอบและปิดงาน

✓ ส่งมอบสินค้าถึงปลายทาง
✓ อัพเดท "ส่งมอบแล้ว"
✓ บันทึกข้อมูลตู้กลับ
✓ ปิดงาน และสร้างรายงาน

7. Tips & Tricks

💡 ใช้ Auto-Complete ให้เป็น

พิมพ์แค่ 2-3 ตัวอักษรแรก ระบบจะแนะนำข้อมูลจาก Master Data ทำให้ไม่ต้องพิมพ์ซ้ำ และลดข้อผิดพลาด

🔍 ค้นหาอย่างรวดเร็ว

ช่องค้นหาที่ Dashboard สามารถค้นหาได้ทั้ง: RN Number, เบอร์ตู้, ชื่อลูกค้า, หรือแม้แต่ชื่อคนขับ - พิมพ์ไปค้นไป Real-time

⚡ Quick Actions คือหัวใจ

ใช้ Quick Actions แทนการเข้าเมนู จะเร็วกว่า 3 เท่า - ทำงานซ้ำ ๆ ได้รวดเร็วมาก

📱 ใช้บนมือถือได้

ระบบรองรับมือถือ - คนขับสามารถอัพเดทสถานะจากมือถือได้ทันที ไม่ต้องรอกลับออฟฟิศ

🎉 พร้อมใช้งานแล้ว!

หากมีคำถามเพิ่มเติม สามารถติดต่อทีม IT Support
หรือดูวิดีโอสอนใช้งานได้ที่เมนู "🎬 วิดีโอสอนใช้งาน"
