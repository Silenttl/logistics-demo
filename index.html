1. ภาพรวมระบบ 3 ส่วน

ระบบแบ่งออกเป็น 3 ส่วนหลัก ที่เชื่อมโยงกัน เข้าถึงได้จากปุ่ม Quick Actions:

🏠 หน้าหลัก

Portal กลาง — สร้างงาน จัดรถ อัพเดทสถานะ สร้างเอกสาร ดูรายการงานทั้งหมด ระบบ Auto-complete

📦 Container Hub

บริหารตู้คอนเทนเนอร์ — Container ID Card · แจ้งซ่อม 6 ขั้นตอน · งานช่าง · อะไหล่ · EIR Gate-In/Out · PM Schedule · Temperature Log · Photo Gallery

🚛 Fleet Hub

บริหารกองรถ — จัดรถ+AI แนะนำ · ติดตามรถ Real-time · ค่าเที่ยว · น้ำมัน+เรท · KPI คนขับ · ทะเบียนรถ/เอกสาร · แจ้งซ่อมรถ

ใช้รหัสเดียวกันได้ในทุกระบบ — login ครั้งเดียว ระบบจำ session ข้ามหน้า

👔 ผู้จัดการ manager mgr123 ทุกระบบ ทุกหน้า ทุกฟีเจอร์
📞 CS / ประสานงาน cs cs123 หน้าหลัก + Container Hub (Dashboard, ID Card, EIR, ซ่อม)

📋 คนจัดรถ dispatch disp123 Fleet Hub (Dashboard, จัดรถ, ติดตาม, แจ้งซ่อม)

3. 👑 Admin / ผู้จัดการ

เข้าด้วย: admin / admin123 หรือ manager / mgr123
🏠 หน้าหลัก
  • ดู Dashboard ภาพรวมงาน สถิติ KPI รายเดือน
  • สร้างงานใหม่ / จัดรถ / อัพเดทสถานะ / สร้างเอกสาร
  • ค้นหา RN, เบอร์ตู้, ชื่อลูกค้าได้ทุกรูปแบบ
📦 Container Hub — กด "จัดการตู้ Container"
  • Dashboard ตู้: สถิติ AV/DM/CL รวม
  • ค้นหาตู้ → ดู ID Card เต็มรูปแบบ (ประวัติ, PM, อุณหภูมิ, ภาพ)
  • อนุมัติ/ปฏิเสธ ใบแจ้งซ่อมทุกระดับ รวมถึง WO มูลค่าสูง
  • จัดการ PM Schedule, EIR Gate-In/Out
  • ดูสต๊อคอะไหล่ อนุมัติการสั่งซื้อ
🚛 Fleet Hub — กด "ระบบรถ Fleet Hub"
  • Dashboard: OTP, Acceptance Rate, Safety Score, km/L
  • สร้างงาน จัดรถ อนุมัติ/ปฏิเสธใบซ่อมรถ
  • ดูและอนุมัติการจ่ายค่าเที่ยวรายคนขับ
  • ตั้งเรทน้ำมัน ดูประสิทธิภาพ km/L ต่อรถ
  • ดูโปรไฟล์คนขับ KPI ครบ + ตรวจเอกสารรถ

4. 📞 CS / ประสานงาน

เข้าด้วย: cs / cs123  |  ใน Fleet Hub ใช้: coord / coord123
🏠 หน้าหลัก — งานหลักของ CS
  1. กด "สร้างงานใหม่" → กรอก RN, ลูกค้า (Auto-complete), เบอร์ตู้, เส้นทาง → บันทึก
  2. กด "จัดรถ" → เลือกงาน → เลือกรถ+คนขับ → ยืนยัน
  3. กด "อัพเดทสถานะ" → เลือกงาน → เลือกสถานะใหม่ → บันทึก
  4. ค้นหาจากช่อง Search ด้วย RN Number หรือเบอร์ตู้
📦 Container Hub — หน้าที่เข้าถึงได้
  • Dashboard — สถิติตู้รวม AV/DM/CL
  • ID Card — ค้นหาตู้ ดูประวัติ สถานะ ตำแหน่ง
  • EIR — บันทึก Gate-In / Gate-Out พร้อม Damage Checklist
  • แจ้งซ่อม — ยื่นใบแจ้งซ่อมแทนลูกค้าได้
🚛 Fleet Hub (coord) — ติดตามและประสานงาน
  • Dashboard — สถานะรถและ KPI รวม
  • ติดตามรถ — ดูรถที่วิ่งอยู่ ติดต่อคนขับ กด "ส่งของแล้ว"
  • จัดรถ — ดูคิวงาน จัดรถเบื้องต้น ดูรถว่าง

5. 🔧 ช่างเทคนิค

เข้าด้วย: tech / tech123  |  เข้าได้เฉพาะ Container Hub
🔧 งานช่าง — ขั้นตอนการทำงาน Work Order
  1. Login → ระบบพาเข้าหน้า "งานช่าง" อัตโนมัติ
  2. ดู Work Order ที่ได้รับมอบหมาย
  3. กด "เริ่มงาน" → ระบบบันทึกเวลาเริ่ม
  4. ลาก Progress Bar อัพเดทความคืบหน้า (0–100%)
  5. กด "เบิกอะไหล่" → เลือกรายการ → จำนวน → ยืนยัน
  6. บันทึก Labor Hours → กด "เพิ่มแถว" → ใส่ช่าง, ชั่วโมง
  7. กด "ปิด Work Order" เมื่องานเสร็จสมบูรณ์
📦 อะไหล่ — จัดการสต๊อคคลัง
  • ดูสต๊อคทั้งหมด — เขียว พร้อม | เหลือง ใกล้หมด | แดง ต้องสั่งเพิ่ม
  • กด "เบิกอะไหล่" → ระบุรายการ จำนวน → ยืนยัน
  • กด "รับอะไหล่" เมื่อของสั่งซื้อมาถึง → อัพสต๊อคอัตโนมัติ

6. 📋 คนจัดรถ / Dispatcher

เข้าด้วย: dispatch / disp123  |  เข้าได้เฉพาะ Fleet Hub
📋 จัดรถ — สร้างและมอบหมายงาน
  1. เข้าหน้า "จัดรถ (Dispatch)"
  2. กรอกฟอร์มซ้าย: Booking No., ต้นทาง, ปลายทาง, ระยะทาง (km), ประเภทตู้
  3. กด "AI แนะนำรถ" → ระบบวิเคราะห์หารถที่เหมาะสม (ประเภทตู้ + OTP คนขับ)
  4. กด "บันทึกงาน" → งานขึ้นคิว
  5. ในตาราง กด "จัดรถ" → เลือกรถ+คนขับ → ยืนยัน
  6. หรือกด "เลือก" จากตารางรถว่างด้านล่าง
📡 ติดตามรถ — อัพเดทสถานะ
  • ดูรถทุกคันที่วิ่งอยู่ + ETA ปลายทาง
  • กด "ติดต่อ" → ดูเบอร์โทร + Line ID คนขับ
  • กด "ส่งของแล้ว" เมื่อรถถึงปลายทาง → สถานะเปลี่ยนเป็น "เสร็จแล้ว"
🔧 แจ้งซ่อมรถ — อนุมัติและปิดงาน
  • กด "อนุมัติ" ต่อใบที่สถานะ "รออนุมัติ" → ส่งให้ช่างดำเนินการ
  • กด "ซ่อมเสร็จ" เมื่องานซ่อมเสร็จ → รถกลับมาสถานะ "ว่าง"
  • กด "แจ้งซ่อมใหม่" เพื่อยื่นใบในนามตัวเอง

7. 💰 ฝ่ายการเงิน

เข้าด้วย: finance / fin123  |  เข้าได้เฉพาะ Fleet Hub
💰 ค่าเที่ยว — คำนวณและจ่ายเงิน
  1. เข้าหน้า "ค่าเที่ยว"
  2. ตั้งค่าเรทในส่วน "ตั้งค่าเรทค่าเที่ยว": เรทมาตรฐาน (บาท/km), เรทเร่งด่วน, โบนัส OTP → กด "บันทึกเรท"
  3. ตรวจตารางรายคนขับ: เที่ยว × เรท + โบนัส = ยอดสุทธิ
  4. กด "จ่ายเงิน" ต่อแถว เมื่อโอนเงินแล้ว → สถานะเปลี่ยนเป็น "จ่ายแล้ว"
  5. กด "Export" เพื่อดาวน์โหลดสรุปประจำเดือน
⛽ น้ำมัน — บันทึกและติดตามต้นทุน
  1. อัพเดท เรทน้ำมัน ในกล่องซ้าย (บาท/ลิตร) → กด "อัพ"
  2. บันทึกการเติม: เลือกรถ → วันที่ → จำนวนลิตร → เลขไมล์ → กด "บันทึก"
  3. ระบบคำนวณ km/L อัตโนมัติ + ต้นทุนรวม
  4. ดูกราฟ "ประสิทธิภาพน้ำมันต่อรถ" เปรียบเทียบทั้งกองรถ

8. 🚚 คนขับรถ

เข้าด้วย: driver / driver123  |  เข้าได้เฉพาะหน้า "แจ้งซ่อม" (ทั้ง Container Hub และ Fleet Hub)
🚗 แจ้งซ่อมรถ (Fleet Hub) — ขั้นตอน
  1. เปิด fleet-hub.html → Login → ระบบพาเข้าหน้าแจ้งซ่อมอัตโนมัติ
  2. กด "แจ้งซ่อมใหม่"
  3. เลือกทะเบียนรถ → อธิบายอาการ/ปัญหาชัดเจน
  4. เลือกความเร่งด่วน: 🟢 ต่ำ / 🟡 กลาง / 🔴 สูง
  5. ใส่ชื่อผู้แจ้ง → กด "ส่งใบแจ้งซ่อม"
  6. รอทีมจัดรถ/ผู้จัดการอนุมัติ
💡 ระดับความเร่งด่วน
  • 🟢 ต่ำ — ยังขับได้ ซ่อมได้ภายหลัง เช่น ไฟขาด เบาะฉีก
  • 🟡 กลาง — ซ่อมภายใน 3 วัน เช่น แอร์ไม่เย็น น้ำมันรั่วนิดหน่อย
  • 🔴 สูง — รถออกงานไม่ได้ ต้องซ่อมด่วน เช่น ยางแตก เบรคไม่ดี

9. 📄 ฝ่ายเอกสาร

เข้าด้วย: doc / doc123  |  เข้าได้: หน้าหลัก (เต็ม) + Container Hub (Dashboard, ID Card)
🏠 หน้าหลัก — งานเอกสาร
  1. กด "สร้างเอกสาร" → เลือกประเภท → กรอกข้อมูล → บันทึก
  2. ดูสถานะเอกสารในรายการงาน — ไอคอนสีแสดงสถานะ
  3. ค้นหาเอกสารด้วย RN Number ในช่อง Search
📦 Container Hub — ดูข้อมูลตู้
  • Dashboard — สถิติตู้ AV/DM/CL สำหรับอ้างอิงในเอกสาร
  • ID Card — ค้นหาเบอร์ตู้ ดูประวัติครบ ใช้ประกอบการทำเอกสาร

10. 💡 Tips & Tricks

⚡ Auto-Complete ประหยัดเวลา

พิมพ์แค่ 2-3 ตัวอักษรแรก ระบบแนะนำทันที — ลูกค้า, ล้ง, เบอร์ตู้ ไม่ต้องจำทั้งหมด

🤖 AI แนะนำรถ (Fleet Hub)

กด "AI แนะนำรถ" ก่อนสร้างงาน — วิเคราะห์ประเภทตู้ + OTP + Safety Score คนขับ ให้รถที่ดีที่สุด

⚠️ แจ้งเตือนเอกสารรถ

Fleet Hub → Dashboard แสดงแจ้งเตือนเมื่อ ภาษี/ประกัน/พรบ. จะหมดอายุใน 30 วัน — ดูแถบสีแดงด้านล่าง KPI

📱 รองรับ Mobile

ทุกระบบรองรับมือถือ — คนขับแจ้งซ่อม, CS อัพเดทสถานะ ได้จากโทรศัพท์ทันที ไม่ต้องรอกลับออฟฟิศ

🔑 Session ข้ามหน้าอัตโนมัติ

Login ครั้งเดียว กด "จัดการตู้ Container" หรือ "ระบบรถ Fleet Hub" ได้เลย — ไม่ต้อง Login ซ้ำทุกหน้า

🎉 พร้อมใช้งานแล้ว!
